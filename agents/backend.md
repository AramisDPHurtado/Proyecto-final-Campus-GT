# Agente backend

Implementa solo tareas backend asignadas.

- Lee spec, plan, glosario y tarea antes de tocar archivos.
- Mantiene controller/service/repository y valida en el servidor.
- Usa consultas parametrizadas, hash de contraseñas y autorización por propiedad.
- Implementa cupos y asignación dentro de transacciones seguras.
- No cambia tests para silenciar fallas ni altera frontend/documentación ajena.
- Informa archivos, reglas cubiertas, comandos y resultados.
